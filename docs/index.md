# Sieve

[![CI Status](https://github.com/AY2627S1-CS2103T-T08-4/tp/workflows/Java%20CI/badge.svg)](https://github.com/AY2627S1-CS2103T-T08-4/tp/actions)
[![codecov](https://codecov.io/gh/AY2627S1-CS2103T-T08-4/tp/branch/master/graph/badge.svg?token=KSCZ68V282)](https://codecov.io/gh/AY2627S1-CS2103T-T08-4/tp)

![Ui](images/Ui.png)

**Sieve is a desktop app that helps self-employed private tuition teachers in Singapore keep track of their clients.** While it has a GUI, most of the user interactions happen using a CLI (Command Line Interface), so tutors who type fast can find and update any client's details in seconds.

* If you are interested in using Sieve, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing Sieve, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
